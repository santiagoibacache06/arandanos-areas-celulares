
# Datos del estudio de arándanos

## 1. Descripción

El proyecto se basa en mediciones anatómicas realizadas en frutos de tres variedades de arándano.

El conjunto de datos original contiene 72 observaciones, correspondientes a 24 registros por cada variedad, identificadas mediante los códigos 1, 2 y 3.

Se consideran cuatro variables anatómicas:

- Área celular del mesocarpo medio.
- Área celular del mesocarpo externo.
- Medición celular de la epidermis.
- Medición celular de la hipodermis.

## 2. Procedencia de los datos

Los datos provienen de un archivo Excel asociado a un trabajo académico de investigación.

Las observaciones originales no están disponibles públicamente en este repositorio.

## 3. Confidencialidad

Los archivos experimentales se mantienen fuera del repositorio público hasta contar con las autorizaciones correspondientes.

Esta decisión permite documentar el proyecto sin divulgar mediciones originales ni información de investigación no autorizada.

## 4. Aspectos pendientes de validación

Antes de realizar el análisis definitivo, es necesario:

1. Confirmar los nombres de las tres variedades.
2. Verificar las unidades de las variables anatómicas.
3. Confirmar el significado de los registros identificados como `sd`.
4. Revisar la estructura de muestreo y las repeticiones experimentales.

## 5. Uso previsto

Los datos podrán analizarse localmente utilizando Python y Pandas para obtener estadísticas descriptivas y elaborar gráficos comparativos.

Los análisis y resultados solo podrán difundirse cuando exista autorización para ello.
